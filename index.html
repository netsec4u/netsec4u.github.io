🔒 NetSec4U Repositories

A quick-access directory for open-source SQL Server tools and projects.

  • SqlServerTools

    This module contains functions to leverage the .NET Sql Client and SQL Management Object (SMO). Originally created to provide SQL Server support beyond what SqlPS provided. More recently, it has transition to compliment the SqlServer module. It is not a replacement for the SqlServer module. One key feature of this module is it promotes session reuse for both SMO and SQL Client.

  • SqlServerMaintenance

    This module contains functions for SQL Server maintenance. These include backups and restore of databases, index and statistics maintenance, and database integrity checks and more.

  • SqlServerAlwaysOnTools

    This module contains functions for SQL Server AlwaysOn management.

  • SqlServerConfiguration

    This module contains functions to configure SQL Server.

  • SqlServerAgentTools

    This module contains functions to configure SQL Server Agent. This includes creations and management of jobs.

  • SqlDataTools

    Module contains functions to import and export data from SQL Server. The module uses a template repository that contains information to perform the import or export. The import templates provide data definitions to validate the data within the delimited text file. The export templates provide the query to define the data to be exported.
